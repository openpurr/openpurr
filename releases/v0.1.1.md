A small release after [0.1.0](https://github.com/openpurr/openpurr/releases/tag/v0.1.0): free-plan usage alerts, everything an app needs to connect in one place, and the CLI on npm.

## What's new

**Free-plan usage alerts (Lite)**
- openpurr warns you before Cloudflare's free-plan daily limits stop your deployment. Past a limit, SDK calls fail and purchases stay queued on devices until 00:00 UTC. The limits are 100,000 Workers requests, 5,000,000 D1 rows read and 100,000 D1 rows written a day.
- It warns at 75% of a limit, or when today's pace would pass it, and fails the check at 90%.
- The alerts appear in a dashboard banner, a **Daily usage** card under Settings, and a check in `doctor` and `check_setup`.
- To turn them on, set a Cloudflare API token with Account Analytics: Read as the back office's `CLOUDFLARE_ANALYTICS_TOKEN` secret. On Workers Paid, set the plan in Settings and usage becomes information only.

**Connecting an app**
- **Configuration → Apps and products** now shows everything an app needs:
  - the SDK URL;
  - each app's SDK keys;
  - ready-to-paste setup code for Swift, Kotlin, Flutter and React Native, with the URL and key filled in;
  - each store's notification URL, and where to paste it.
- **The SDK URL** is one deployment-wide setting, under Settings → This deployment. Until you set it, openpurr shows a guess from the workers.dev address and labels it as one.
- `get_config` and `openpurr config` include the SDK URL, the SDK keys and the notification URLs. `doctor` has a new SDK URL check.

**CLI on npm**
- The CLI is now published as [`@openpurr/cli`](https://www.npmjs.com/package/@openpurr/cli). Install it with `npm install -g @openpurr/cli`, or run `npx @openpurr/cli`. The command is still `openpurr`.
- The package now has a README on npm.
- Releases now publish it automatically, with a provenance attestation.

## Upgrading

Lite deploys from `main`, so a deployment that follows `main` already has these changes. No database or app changes are needed. To get usage alerts, add the `CLOUDFLARE_ANALYTICS_TOKEN` secret:

```sh
cd lite && npx wrangler secret put CLOUDFLARE_ANALYTICS_TOKEN --env office
```

If you used `npx openpurr` before, switch to `npx @openpurr/cli`.
